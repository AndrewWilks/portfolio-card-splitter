## Rollback SQL

```sql
-- Rollback: Restore calculated field
-- Note: Values would need to be recalculated
ALTER TABLE allocations
  ADD COLUMN calculated_amount_cents BIGINT NOT NULL DEFAULT 0;

-- Update with calculated values
UPDATE allocations
SET calculated_amount_cents = CASE
  WHEN rule = 'basisPoints' THEN
    (SELECT amount_cents * percentage / 10000 FROM transactions WHERE id = transaction_id)
  ELSE amount_cents
END;
```
