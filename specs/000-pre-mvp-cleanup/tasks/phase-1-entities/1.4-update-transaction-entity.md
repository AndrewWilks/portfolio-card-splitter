# Task 1.4: Update Transaction Entity

**Phase**: 1 - Entities  
**Status**: ⬜ Not Started  
**Estimated Time**: 1-2 hours

## Goal

Update Transaction entity to include cardAccountId (required) and cardId (optional) fields for linking transactions to CardAccounts and Cards.

## Context

Currently, Transaction entity does not reference CardAccounts or Cards. This update is critical for MVP because:

- **Every transaction** must belong to exactly one CardAccount
- **Transactions can optionally** reference a specific Card for attribution
- **Outstanding balances** are calculated per CardAccount
- **Dashboard filtering** requires CardAccount grouping

## Example Updates

### Entity Changes

```typescript
export class Transaction extends Entity {
  private _cardAccountId: string; // NEW
  private _cardId?: string; // NEW
  private _merchantId: string;
  private _description: string;
  private _amountCents: number;
  private _type: TransactionType;
  private _transactionDate: Date;
  private _createdById: string;

  constructor(data: TransactionData) {
    super(data);
    const validated = Transaction.schema.parse(data);
    this._cardAccountId = validated.cardAccountId; // NEW
    this._cardId = validated.cardId; // NEW
    this._merchantId = validated.merchantId;
    this._description = validated.description.trim();
    this._amountCents = validated.amountCents;
    this._type = validated.type;
    this._transactionDate = new Date(validated.transactionDate);
    this._createdById = validated.createdById;
  }

  get cardAccountId(): string {
    return this._cardAccountId;
  } // NEW

  get cardId(): string | undefined {
    return this._cardId;
  } // NEW

  // ... existing getters

  override toJSON(): TransactionData {
    return {
      ...super.toJSON(),
      cardAccountId: this._cardAccountId, // NEW
      cardId: this._cardId, // NEW
      merchantId: this._merchantId,
      description: this._description,
      amountCents: this._amountCents,
      type: this._type,
      transactionDate: this._transactionDate,
      createdById: this._createdById,
    };
  }
}
```
