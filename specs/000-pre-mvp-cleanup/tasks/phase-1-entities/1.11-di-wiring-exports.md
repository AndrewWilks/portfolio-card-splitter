## Notes

- **Order Matters**: Entities → Repositories → Services → Routes
- **Circular Dependencies**: Avoid by using factory pattern
- **Import Paths**: Use `@backend/` and `@shared/` aliases
- **Type Safety**: TypeScript will catch most wiring issues
- **Runtime Errors**: Server startup will reveal DI issues
- **404 vs 401**: Routes return 401 (auth) not 404 (missing)
