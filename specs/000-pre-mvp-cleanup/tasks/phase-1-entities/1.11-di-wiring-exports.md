## Common Issues to Check

**Missing Exports:**

```typescript
// ❌ Missing export
class CardAccountRepository {}

// ✅ Proper export
export class CardAccountRepository {}
```

**Missing from Index:**

```typescript
// ❌ Not re-exported
// (file exists but not in index.ts)

// ✅ Re-exported
export { CardAccountRepository } from "./cardAccountRepository.ts";
```

**Missing DI Factory:**

```typescript
// ❌ Service used but no factory
const service = new CardAccountService(...); // Direct instantiation

// ✅ Factory exists
export function createCardAccountService() {
  return new CardAccountService(...);
}
```

**Missing Route Mount:**

```typescript
// ❌ Route handler exists but not mounted
// (factory in di/routes.ts but not in server.ts)

// ✅ Route mounted
backend.get("/api/card-accounts", di.createApiCardAccountsList());
```

**Missing Table Export:**

```typescript
// ❌ Table schema exists but not exported
// (tables/cardAccounts.ts exists but not in tables/index.ts)

// ✅ Table exported
export { cardAccounts } from "./cardAccounts.ts";
```

## Notes

- **Order Matters**: Entities → Repositories → Services → Routes
- **Circular Dependencies**: Avoid by using factory pattern
- **Import Paths**: Use `@backend/` and `@shared/` aliases
- **Type Safety**: TypeScript will catch most wiring issues
- **Runtime Errors**: Server startup will reveal DI issues
- **404 vs 401**: Routes return 401 (auth) not 404 (missing)
