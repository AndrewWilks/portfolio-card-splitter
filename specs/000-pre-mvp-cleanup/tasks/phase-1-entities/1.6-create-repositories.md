## Goal

Create repository layer for CardAccount, CardAccountSettings, and Card entities following the established Repository base class pattern.

## Context

The project uses a base `Repository<T>` class that provides standard CRUD operations:

- `findById(id: string)` - Find single entity by ID
- `findAll()` - Find all entities ordered by createdAt
- `save(entity)` - Insert or update entity
- `delete(id: string)` - Soft or hard delete based on entity type

Repositories extend this base class and add custom query methods specific to each entity type.

## Implementation Details

### CardAccountRepository

```typescript
import { CardAccount } from "@shared/entities";
import { Repository } from "./base/repository.ts";
import { eq, and } from "drizzle-orm";
import { Tables } from "@db/tables";
import { objectKeysToCamel } from "@shared/utilities";

export class CardAccountRepository extends Repository<"CardAccount"> {
  constructor() {
    super("CardAccount");
  }

  async findByOwnerId(ownerId: string): Promise<CardAccount[]> {
    const results = await this.dbClient
      .select()
      .from(Tables.cardAccounts)
      .where(eq(Tables.cardAccounts.ownerId, ownerId))
      .orderBy(Tables.cardAccounts.createdAt);

    return results.map((row) => {
      const camelCaseData = objectKeysToCamel(row as Record<string, unknown>);
      return new CardAccount(camelCaseData as any);
    });
  }

  async findActiveByOwnerId(ownerId: string): Promise<CardAccount[]> {
    const results = await this.dbClient
      .select()
      .from(Tables.cardAccounts)
      .where(
        and(
          eq(Tables.cardAccounts.ownerId, ownerId),
          eq(Tables.cardAccounts.isActive, true)
        )
      )
      .orderBy(Tables.cardAccounts.createdAt);

    return results.map((row) => {
      const camelCaseData = objectKeysToCamel(row as Record<string, unknown>);
      return new CardAccount(camelCaseData as any);
    });
  }
}
```

### CardAccountSettingsRepository

```typescript
import { CardAccountSettings } from "@shared/entities";
import { Repository } from "./base/repository.ts";
import { eq } from "drizzle-orm";
import { Tables } from "@db/tables";
import { objectKeysToCamel } from "@shared/utilities";

export class CardAccountSettingsRepository extends Repository<"CardAccountSettings"> {
  constructor() {
    super("CardAccountSettings");
  }

  async findByCardAccountId(
    cardAccountId: string
  ): Promise<CardAccountSettings | null> {
    const results = await this.dbClient
      .select()
      .from(Tables.cardAccountSettings)
      .where(eq(Tables.cardAccountSettings.cardAccountId, cardAccountId))
      .limit(1);

    if (results.length === 0) {
      return null;
    }

    const camelCaseData = objectKeysToCamel(
      results[0] as Record<string, unknown>
    );
    return new CardAccountSettings(camelCaseData as any);
  }
}
```

## Notes

- **Repository pattern**: All repositories follow the same pattern - extend base, add custom queries
- **Query pattern**: Use Drizzle ORM with Tables import, eq/and for conditions
- **Data conversion**: Always use objectKeysToCamel for DB row → entity data
- **Return types**: Single entity returns `Entity | null`, multiple returns `Entity[]`
- **Soft delete**: All three entities use soft delete (isActive flag)
- **DI pattern**: Factory functions in di/repositories.ts for dependency injection
- **Test pattern**: Only test instantiation and method existence (no database)
